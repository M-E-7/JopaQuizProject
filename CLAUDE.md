# JopaQuizProject

Personal quiz application. It serves multiple-choice questions (4 options, exactly one correct), tracks the score (right/wrong), and for each question references the part of the source document where the answer is found.

Questions are generated by Claude from documents the user provides, via a dedicated Claude skill (planned: `.claude/skills/generate-quiz/`).

## Constraints

- Personal use only — not published to any app store.
- Must run on **Windows** and **Android** (Android via sideloaded APK or equivalent).
- The user works in **JavaScript / TypeScript**; the stack should be from that family.

## Source documents

- **.docx** — references use the heading path to the section plus a verbatim quote of the passage containing the answer.
- **.csv** — content varies: may be a fact table (e.g. term/definition) or ready-made Q&A rows. References use the row number, column name(s) and cell text.
