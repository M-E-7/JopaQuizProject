# JopaQuiz app

React + TypeScript + Vite PWA. See the root [`CLAUDE.md`](../CLAUDE.md) for the project overview and decisions.

```bash
npm install      # once
npm run dev      # dev server with hot reload (http://localhost:5173/JopaQuizProject/)
npm run build    # type-check + production build into dist/
npm run preview  # serve the production build locally
npm run lint     # oxlint
```
